Dicas para criar o template no Word
  • Escreva as tags diretamente no texto, sem espaços extras: {{nome_funcionario}}
  • As tags diferenciam maiúsculas/minúsculas — use sempre letras minúsculas.
  • Se a tag aparecer em branco no PDF, verifique se o campo está preenchido no cadastro do funcionário ou em Configurações.
  • O campo estado_civil deve ser preenchido manualmente no cadastro do funcionário (não vem da Secullum).
  • Use {{data_admissao}} para datas em contratos formais (ex.: "5 de março de 2024").
